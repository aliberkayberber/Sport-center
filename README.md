# Sport Center

## Overview
Sport Center is a powerful application designed to manage and streamline the operations of a sports facility. It provides features for scheduling, member management, and facility booking.

## Features
- **Member Management**: Easily add, update, and manage member information.
- **Scheduling**: Create and manage schedules for various sports and activities.
- **Facility Booking**: Book facilities and track availability in real-time.
- **Notifications**: Send notifications to members about upcoming events and bookings.
- **Reports**: Generate reports on facility usage, member activity, and more.

## Installation
1. Clone the repository:
    ```bash
    git clone https://github.com/aliberkayberber/Sport-center
    ```
2. Navigate to the project directory:
    ```bash
    cd sport-center
    ```
3. Install dependencies:
    ```bash
    npm install
    ```

## Usage
1. Start the application:
    ```bash
    npm start
    ```
2. Open your browser and navigate to `https://powerfullgym.netlify.app/`.
